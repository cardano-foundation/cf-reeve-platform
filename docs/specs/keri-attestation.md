  IT SUPPORTS TWO TRUST MODELS, AND BOTH ARE REQUIRED:                                                                                                                                                        
    chained: true   -> the chain must terminate in one of the schema's trusted ROOTS   (vLEI Legal Entity -> GLEIF)                                                                                           
    chained: false  -> the issuer AID must be in the schema's trusted ISSUERS          (Foundation Employee)                                                                                                  
  Foundation Employee — the schema currently used for tests — is the standalone model. A root-chaining-only design cannot support it and is wrong.
